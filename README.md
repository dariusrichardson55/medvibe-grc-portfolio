# GRC ISO/IEC 27001 Portfolio

## Overview
This repository contains a practical implementation portfolio of a mini-Information Security Management System (ISMS) modelled for **MedVibe Health**, a cloud-native, healthcare B2B SaaS startup. 

The documentation demonstrates an end-to-end mapping of business risk down to operational policies, technical controls, and framework alignment under **ISO/IEC 27001:2022**.

## Portfolio Artefacts

* **01_Company_Context.mb**  
  **Establishes the business boundaries, remote-first asset scope, and primary regulatory triggers (including PHI and financial transaction data).**

* **02_Risk_Assessment_Register.pdf**  
  **Quantifies and scores technical cloud vulnerabilities mathematically (Likelihood × Impact) alongside actionable, business-aligned mitigation plans.**

* **03_Information_Security_Policy.pdf**  
  **Formal, executive-level corporate governance mandates defining top-level security objectives and management commitment.**

* **04_Access_Control_Policy.pdf**  
  **Detailed engineering sub-policies architecting strict technical control parameters, including Least Privilege, mandatory Multi-Factor Authentication (MFA), and Mobile Device Management (MDM).**

* **05_Statement_of_Applicability.pdf**  
  **The core compliance defence document, explicitly mapping technical cloud implementations back to formal ISO/IEC 27001:2022 Annex A controls for audit readiness.**
